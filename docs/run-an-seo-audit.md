**SEO Audit** checks every page of your site for search engine problems and lists what to fix first.

## Run an audit

1. Open **SEO Audit** and press **Run audit**.
2. Keep the page open until it finishes. It shows how many pages it has checked.

## Read the results

- The **Site score** out of 100 sums up the whole site.
- **Priority Fixes** lists the issues in the order to fix them, with the pages affected and how to fix each one.
- **What Was Checked** shows each check and its result.

## Track progress

**Runs** lists past audits with their score, the pages checked, the issues found and the change **since the previous run**, so you can see whether your fixes are working.

## Settings

Under **Settings** you can limit the **Most pages per run** and set a **Pause between requests** to go easy on the site. **Crawl address** is only needed if the server cannot reach its own public address, so leave it blank normally.
